# Data model and content schemas

**Docs only.** Schemas below are the contract for future JSON content packs and local progress. Example JSON appears only inside this file (fenced blocks). Do not treat this repository as application source.

Path convention for packs (when app code exists elsewhere):

```text
content/
  skills/
    price.json
    refuse.json
    unwell.json
    ...
  roles/
    shop_checkout.json
    ...
  onboarding/
    letters.json
    word_cards.json
    kindergarten.json
  audio/
    ...
```

## Enums

### `reviewStatus`

```json
{
  "reviewStatus": ["draft", "rejected", "accepted", "allowed_to_generate_from"]
}
```

- `draft` — authored or AI-proposed; not shown to learners.
- `rejected` — failed fluff filter or editor cut.
- `accepted` — may appear in lessons.
- `allowed_to_generate_from` — accepted **and** safe as a seed for new examples.

### `progressMarker`

```json
{
  "progressMarker": ["unseen", "weak", "review", "done"]
}
```

### `lessonStepType`

```json
{
  "lessonStepType": [
    "assemble",
    "substitute",
    "choose",
    "listen_extract",
    "speak_formula",
    "fill_gap"
  ]
}
```

## Skill

```json
{
  "$schemaComment": "Skill — nucleus of the catalog",
  "id": "string (snake_case, stable)",
  "taskRu": "string — what the learner must get done (Russian)",
  "taskEn": "string — internal English gloss for authors",
  "success": "string — what a stranger accepts",
  "frames": ["Frame"],
  "slots": ["Slot"],
  "typicalErrors": ["string"],
  "bans": ["Ban"],
  "reviewStatus": "reviewStatus",
  "allowGenerate": "boolean — true only if reviewStatus is allowed_to_generate_from",
  "audioRefs": ["AudioRef"],
  "trackTags": ["shop", "travel", "household", "tech", "service_state", "talk_repair"]
}
```

## Frame

```json
{
  "id": "string",
  "pattern": "string — English skeleton with {slotId} placeholders",
  "literalGlossRu": "string — short Russian gloss of function, not a translation drill",
  "requiredSlotIds": ["string"],
  "exampleFilled": "string — one accepted filled line"
}
```

## Slot

```json
{
  "id": "string",
  "role": "object | number | unit | place | time | condition | other",
  "values": [
    {
      "en": "string",
      "ruHint": "string"
    }
  ],
  "notes": "string | null"
}
```

## Ban

```json
{
  "id": "string",
  "rule": "string — machine-checkable or editor checklist item",
  "examplesReject": ["string"]
}
```

## AudioRef

```json
{
  "id": "string",
  "path": "content/audio/.... (relative)",
  "textEn": "string — transcript matching an accepted line",
  "skillId": "string",
  "frameId": "string | null"
}
```

## LessonStep (runtime plan for one skill lesson)

```json
{
  "stepId": "string",
  "type": "lessonStepType",
  "skillId": "string",
  "promptRu": "string",
  "payload": {
    "frameId": "string | null",
    "parts": ["string"],
    "correctOrder": ["string"] ,
    "slotId": "string | null",
    "options": ["string"],
    "correctOption": "string | null",
    "audioRefId": "string | null",
    "extractTarget": "price | deadline | place | condition | null",
    "expectedFrameId": "string | null",
    "gapToken": "string | null"
  },
  "onFail": {
    "showBrokenSlot": true,
    "workingPhrase": "string"
  }
}
```

**Decision:** a default lesson for one skill is 4–6 steps mixing at least `assemble`, `substitute`, and one of `listen_extract` / `speak_formula`. Exact mix is generated by `domain.LessonRunner` from the skill record, not authored as a novel.

## Progress model

```json
{
  "learnerId": "local-device",
  "streakDays": 0,
  "stars": 0,
  "hintsAvailable": 0,
  "skills": {
    "price": {
      "marker": "weak",
      "correctStreak": 1,
      "confusedSlotIds": ["object"],
      "lastSeenIso": "2026-09-16T00:00:00+03:00"
    }
  },
  "letters": {
    "A": "known",
    "R": "shaky"
  },
  "wordCards": {
    "top": "known"
  },
  "reviewQueue": [
    {
      "kind": "skill_slot",
      "skillId": "price",
      "slotId": "object",
      "dueIso": "2026-09-17T08:00:00+03:00"
    }
  ],
  "settings": {
    "offlineModelInstalled": false,
    "notificationsForOneAction": true
  }
}
```

**Stars → hints:** domain converts stars to hints at a fixed rate (decision: **5 stars = 1 hint** until content testing says otherwise).

## Role / situation object

```json
{
  "id": "shop_checkout",
  "titleRu": "На кассе",
  "goalRu": "Узнать цену и отказаться от карты, если не нужна",
  "track": "shop",
  "skillIds": ["price", "refuse", "quantity"],
  "allowedFrameIds": ["price.how_much", "refuse.no_thanks", "quantity.need_n"],
  "bans": [
    {
      "id": "no_smalltalk",
      "rule": "No chat about mood, looks, or private life at the till",
      "examplesReject": ["You look nice today", "How is your family?"]
    }
  ],
  "techRules": {
    "workingPath": ["linux", "windows", "android"],
    "appleFraming": "dismissed_poor_gear"
  },
  "reviewStatus": "accepted"
}
```

For non-tech roles, `techRules` may be `null`. For tech roles it is required; Apple may appear only as dismissed poor gear.

## Shop-track frame fill (authoring aid)

For checkout drills, prefer these substitutions together:

| Skill | Frame | Filled example |
| --- | --- | --- |
| `price` | `How much is {object}?` | How much is this detergent? |
| `quantity` | `I need {object} for {number} loads.` | I need detergent for two loads. |
| `refuse` | `I don't need {object}.` | I don't need a discount card. |

Full `quantity` skill record can follow the same schema; v1 pack should include it before shop track ships (see [BUILD.md](BUILD.md)).
