# First-wave skill catalog

Each skill is a record, not a chapter. Fields to fill when authoring:

- id  
- task (what the person is trying to get done)  
- success (what a stranger accepts)  
- frames (2–4)  
- slots (substitutable words)  
- typical errors  
- bans  

## Money and goods

| id | task | success |
| --- | --- | --- |
| price | Find out how much it costs | Learner can ask and understand a price |
| quantity | Say how many / how much | Number + unit understood |
| order | Place a simple order | Staff can fulfill it |
| refuse | Decline an offer | Refusal is clear, not a story |
| replace | Ask to replace an item | Request is specific |
| return | Ask to give it back | Request is specific |
| composition | Ask what it is made of / what’s in it | Answer can be used |
| property | Ask a property (size, color as function, hot/cold) | Usable answer |
| freshness | Ask if it is still good | Yes/no or a date |
| working | Say a thing is broken / not working | The fault is pointed at |

## Time and place

| id | task | success |
| --- | --- | --- |
| time | Ask or say the time of day | Other person can act on it |
| deadline | Ask until when / how long | A date or duration is captured |
| place | Ask or say where | Can walk there |
| route | Ask how to get there | Next step is clear |
| open_closed | Ask if it is open | Yes/no usable |
| announcement | Understand a short public announcement | Extracts the condition (gate, delay, closed) |

## Talk-repair

| id | task | success |
| --- | --- | --- |
| repeat | Ask to say again | Other person repeats |
| slower | Ask to speak slower | Other person slows down |
| clarify | Ask a narrowing question | Ambiguity drops |

## Service state (facts only)

| id | task | success |
| --- | --- | --- |
| unwell | Briefly state feeling unwell to get help or a service | Treated as a fact, not a confession scene |
| pain_place | Name where it hurts | Specific enough for pharmacy / desk |
| cannot_go | State cannot continue walking / traveling | Decision can be made |
| everyday_mishap | Name a concrete mishap (broken cup) as the **reason** for a request | Reason is a fact |
